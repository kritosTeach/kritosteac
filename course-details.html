Course Curriculum

80+ Video Lessons 200+ Exercises 12 Projects 120+ Hours Content

Section 1: Python Fundamentals (Weeks 1-2)

  • Introduction to Python and its applications
  • Setting up development environment (VS Code, PyCharm)
  • Variables, Data Types, and Type Conversion
  • Operators, Expressions, and Input/Output
  • Control Flow: Conditionals (if/elif/else)
  • Loops: for, while, nested loops
  • Functions: definition, parameters, return values
  • Modules, Packages, and PIP package manager
  • Project 1: Calculator Application
  • Project 2: Number Guessing Game

Section 2: Data Structures (Weeks 3-4)

  • Lists: operations, slicing, methods
  • Tuples, Sets, and Frozen Sets
  • Dictionaries: key-value pairs, methods
  • Strings and advanced string methods
  • List Comprehensions and Generator Expressions
  • Working with Files: read, write, append
  • CSV, JSON, and XML file processing
  • Error Handling: try/except/finally
  • Project 3: Contact Management System
  • Project 4: Data Processing Script

Section 3: Object-Oriented Programming (Weeks 5-6)

  • Classes and Objects: attributes and methods
  • Constructors (__init__) and self parameter
  • Inheritance: single, multiple, multilevel
  • Polymorphism and Method Overriding
  • Encapsulation: private and protected members
  • Abstraction and Abstract Classes
  • Magic Methods (Dunder Methods)
  • Properties, Getters, and Setters
  • Project 5: Bank Account System
  • Project 6: E-commerce Product Catalog

Section 4: Advanced Python (Weeks 7-8)

  • Decorators and Function Wrapping
  • Generators and Yield Statements
  • Context Managers and with Statement
  • Multithreading and Multiprocessing
  • Regular Expressions (regex)
  • Lambda Functions and Functional Programming
  • Database Integration: SQLite, PostgreSQL
  • Web Scraping with BeautifulSoup & Scrapy
  • Project 7: Web Scraper for News Articles
  • Project 8: Multi-threaded Download Manager

Section 5: Web Development (Weeks 9-10)

  • Flask Framework: Basics and Routing
  • Templates (Jinja2) and Static Files
  • Forms and User Input Validation
  • Django Framework: Models, Views, Templates
  • REST APIs with Flask-RESTful
  • Authentication and Authorization
  • Database Models with SQLAlchemy
  • Deployment to Heroku/AWS
  • Project 9: Blog Application with Flask
  • Project 10: REST API for Todo App

Section 6: Data Science & Automation (Weeks 11-12)

  • Data Analysis with pandas
  • Numerical Computing with NumPy
  • Data Visualization with Matplotlib & Seaborn
  • Introduction to Machine Learning (scikit-learn)
  • Automation Scripting and Task Scheduling
  • Testing with pytest
  • Code Optimization and Profiling
  • Docker Basics for Python Apps
  • Project 11: Data Analysis Dashboard
  • Project 12: Final Capstone Project
